    HOW IT WORKS

    From ten features to one probability

    The clinical pipeline from the thesis. Steps marked LIVE run on your phone every time you press Predict.

    1. 1

      Input

      Stroke Prediction dataset: 10 clinical features plus the stroke label — gender, age, hypertension, heart disease, ever married, work type, residence, glucose, BMI, smoking.

    2. 2

      Preprocessing LIVE

      Missing values filled by mean imputation; numeric features scaled to 0–1.

      x_imputed = (x₁ + x₂ + … + xₙ) / n x_scaled = (x − x_min) / (x_max − x_min)
    3. 3

      Feature reduction · SSC-AE

      A Sparse Subspace Clustering Autoencoder groups related features and keeps the informative ones.

      L = λ‖W‖₁ + ‖X − WZ‖²₂ A = |Z| + |Zᵀ|
      Stroke-dominantHypertension · Glucose · Heart disease
      LifestyleBMI · Work type · Smoking
      Neutral (dropped)Gender · Age · Ever married · Residence

      10 features → 6. This app uses those 6 directly.

    4. 4

      Attention layer LIVE

      Each factor gets an importance weight for this particular person.

      eᵢ = tanh(W·xᵢ + b) αᵢ = exp(eᵢ) / Σⱼ exp(eⱼ) Z = Σ αᵢ · xᵢ
    5. 5

      Hidden layer · ReLU LIVE

      Learns interactions between the weighted factors.

      h = ReLU(W₁·Z + b₁) ReLU(x) = max(0, x)
    6. 6

      Output · Sigmoid LIVE

      Squashes the result into 0–1. Near 0 is low risk, near 1 is high risk.

      y = 1 / (1 + e^−(W₂·h + b₂))
